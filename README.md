# 🚀 GAccount-Mate (Gmail 账号使用手册与 2FA 实时接码工作台)

> **极简 · 安全 · 离线可用**  
> 专为 Gmail / 谷歌账号用户量身打造的一站式交互指引与安全管理手册。集成纯前端 RFC 6238 TOTP 实时算码引擎、凭据智能拆解、更新 2FA 自动合成与 TXT 存档导出、官方安全风控机制解析及全流程高清图文对照。

---

## 🌟 核心功能特色

### 1. ⚡ 智能卡密拆解与离线 2FA 实时接码
- **多格式智能兼容**：支持 `账号----密码----2FA密钥`、制表符 Tab、竖线 `|` 等多种卡密分隔格式一键解析；
- **纯前端零依赖 TOTP 引擎**：基于 RFC 6238 规范与纯 JavaScript 实现 SHA1/HMAC 算法，无需任何后端服务器或第三方接码接口，完全可在本地（甚至断网离线环境）极速计算 6 位动态验证码；
- **双重交互体验**：提供 30 秒动态环形/条形倒计时、验证码一键复制、剪贴板一键读取与输入框一键清空；
- **账号密码脱敏保护**：密码默认掩码处理，支持一键切换显示与单字段独立复制。

### 2. 🔐 换绑全新 2FA 交互工作台（防呆设计）
- **实时新码校验**：在个人信息设置修改 2FA 时，用户只需在工作台中粘贴谷歌生成的新密钥，页面即刻启动实时算码，无缝配合谷歌官方的第二步输入校验；
- **全自动卡密合成**：自动将原有账号、密码与全新 2FA 密钥拼接为标准格式 `账号----密码----新2FA密钥`；
- **一键复制与 TXT 下载**：提供一键复制完整卡密，以及一键生成并下载标准 `.txt` 安全存档文件，防止用户遗失凭证。

### 3. 📖 1:1 官方级高清图文实操教程
- **完整登录流程（步骤 1.1 ~ 1.6）**：涵盖官网检索、账号密码录入、两步验证输入、国内 +86 手机号与辅助邮箱绑定、跳过家庭住址等各环节；
- **安全设置修改（步骤 2.1 ~ 2.4）**：涵盖修改 2FA 身份验证器、修改登录密码（4步完整实操图解）、绑定/修改恢复手机号（5步完整实操图解，支持中国大陆 +86 手机号）、修改并验证恢复辅助邮箱（4步完整实操图解）；
- **全屏灯箱放大**：支持点击任意截图无损全屏查看细节，支持 ESC 键快捷退出。

### 4. 🛡️ 官方风控机制深度解读与 6 大日常养护防封攻略
- **防封核心口诀与时序链路**：明确“首登成功 ➔ 固定同地区IP与设备养护 3 天 ➔ 更新 2FA 验证器 ➔ 后改密码与绑定个人手机/辅助邮箱”的安全生命周期法则；
- **6 大核心养护支柱**：涵盖单一地区网络稳定性、固定浏览器指纹、改密节奏雷区规避、YouTube/搜索模拟真实用户互动、多账号环境隔离防关联、启用初期低频操作等深度解析；
- **安全养护时间轴（Lifecycle Roadmap）**：直观展示从第 1 天初登适应期、第 2~3 天信任建立期、第 3~7 天完善配置期到 30 天以上长期稳定期的全过程；
- **登录扫码风控自助解封专项指南**：针对登录强制要求扫码且手机扫码报错“我们无法验证您的信息”的死循环场景，提供清晰的 3 步解除指引（静置 3~5 天 ➔ 更换干净住宅 IP 重登 ➔ 选“扫描二维码”通过验证）与三图对照；
- **安全使用提醒**：清晰界定合规使用规范与操作注意事项，协助用户稳健维护账号安全。

### 5. 📱 顶级移动端 UI/UX 体验
- **零横向滚动条**：全站 CSS 针对手机屏幕做了严格的溢出控制与自适应流式排版；
- **手机端固定 Header**：在移动端浏览长页面时，顶部关键操作栏（主题切换、快捷入口）始终固定吸顶；
- **深色/浅色模式**：支持一键切换深色夜间模式，降低视觉疲劳；
- **友好打印排版**：支持 `@media print` 样式优化，可直接一键导出或打印 PDF 使用手册。

## 🛠️ 本地预览与快速上手

由于本项目为 **纯前端零外部依赖** 架构，无需安装 Node.js、Python 或任何构建打包工具：

1. **直接双击打开**：
   在资源管理器中直接双击 `index.html`，即可在任何主流浏览器（Chrome、Edge、Safari、Firefox）中畅享全部功能。

2. **本地 HTTP 预览（可选）**：
   ```bash
   # 使用 Python 启动临时服务
   python -m http.server 8080

   # 或使用 Node.js npx serve
   npx serve .
   ```
   随后在浏览器访问 `http://localhost:8080` 即可。

## 🌐 服务器部署指南 (1Panel / Nginx)

本项目属于纯静态站点，推荐部署在 **1Panel** 面板的静态网站目录下。

### 方式一：首次在 1Panel 站点目录中初始化 Git 并拉取部署

如果您的 1Panel 站点目录（如 `/opt/1panel/www/sites/doc.ap1x.xyz/index`）目前是一个空目录或已有旧静态文件，请在 1Panel 的 **【终端】** 或通过 SSH 登录服务器执行以下命令：

```bash
# 1. 进入站点部署目录
cd /opt/1panel/www/sites/doc.ap1x.xyz/index

# 2. 初始化 Git 仓库
git init

# 3. 添加 GitHub 远程仓库地址
git remote add origin https://github.com/tankeito/gaccount-mate.git

# 4. 拉取远程 main 分支最新代码并强制覆盖到本地
git fetch --all
git reset --hard origin/main

# 5. 确保文件所有者权限正常（通常为 1000:1000 或 www:www）
chown -R 1000:1000 /opt/1panel/www/sites/doc.ap1x.xyz/index
```

### 方式二：后续日常更新代码（极简一行命令）

当您在本地仓库修改并推送（`git push`）新代码到 GitHub 后，只需在 1Panel 终端执行：

```bash
cd /opt/1panel/www/sites/doc.ap1x.xyz/index && git pull origin main
```

即可立即完成生产环境热更新！

## 🔒 隐私与安全性声明

1. **绝对脱敏与无上传机制**：
   本项目所有解析、计算与存储逻辑 **100% 在客户端浏览器本地内存中运行**。无论是账号、明文密码还是 2FA 密钥，都不会被发送至任何云端服务器、第三方统计平台或日志接口。
